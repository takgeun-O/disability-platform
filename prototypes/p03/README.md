최신 개정(§16): Q4에 공식 내구연한 5년과 자동 재지급 아님을 직접 표시하고, 상세 → 현재 결과 복귀 링크를 추가했습니다. 결과가 없으면 빠른 확인으로 이동합니다. 답변 영속저장이나 전역 상태는 추가하지 않았습니다.

## 상담 질문 준비

Guided 결과에 상황별 센터 질문 3개가 바로 표시됩니다. 같은 영역의 “질문 복사하기” 하나로 휴대폰 메모 등에 보관할 수 있습니다. 자동 복사가 실패하면 직접 복사할 텍스트를 표시합니다. 질문 선택·추가·파일 저장·인쇄 전용 버튼과 별도 편집 화면은 제거했습니다.

상세 기준을 보고 상단 복귀 링크를 누르면 응답·제품 선택이 유지됩니다. “이전 질문”은 앞 답변을 수정하며, “처음부터 확인하기”는 응답과 제품 선택을 초기화합니다. 새로고침하면 메모리 내용이 사라지고 요약으로 돌아갑니다(공용 상세 anchor는 해당 Reference로 열림). 기존 `#consultation-preparation` 링크는 결과 또는 첫 질문으로 연결됩니다.

## 센터 방문 전 준비 흐름

- `guided-content.ts`: 검사·신청 전 / 검사 중 / 심사 대기 / 등록 완료 / 모름으로 시작하는 응답과 15개 결과 경로. 보험 자격 모름도 공통 처방·지원 이력 질문을 이어가며 미확인 상태 유지.
- `VisitOverview.tsx`: 질문 위의 고정 5단계 그림. 질문 주제와 결과 상태를 구분하고, 스크롤해도 결과 상태를 바꾸지 않음. 보험 자격·이전 지원 이력 확인은 별도 문구로 표시. 높이 450px 이하에서는 고정 해제.
- `ResultJourney.tsx`, `RegistrationSequence.tsx`: 결과 안에서 기관·역할이 담긴 5단계와 등록 내부 순서를 표시. 완료·현재·확인 필요·이후 과정을 글자로 구분. 읽기 위치 감지 코드는 제거.
- `DetailNavigation.tsx`: 고정 안내의 실제 높이를 반영해 질문·결과와 키보드 초점이 가려지지 않도록 이동 위치 조절.
- `consultation-content.ts`: 각 상황의 센터 질문 3개. 보험 자격이 불명확하면 건강보험 전용 질문을 기본 추천하지 않음.
- `GuidedCheck.tsx`: 질문 아래 현재 상태 → 전체 흐름 → 다음 행동과 문의 문장 → 센터 질문 3개 → 관련 상세. `question-note.ts`는 상태·미확인 항목·문의 문장·질문·확인 목적을 복사문으로 구성.
- `AfterPurchaseGuide.tsx`: 건강보험의 Q4 결과에서 상담 질문 뒤에 표시. 한 번에 받는 돈이 아니라는 요약만 펼쳐 두고, 후속 절차·비용·직접 청구 자료를 각각 접음. 비용 카드는 전체 기준과 공유.
- `BenefitBreakdown.tsx`: 전체 기준과 결과가 공유하는 청구 단계별 비용 카드·전체 합계·지급 조건·출처. 본인부담경감 도움말은 클릭·키보드로 여는 인라인 설명이며 반복된 설명의 ID는 `useId`로 구분.
- `QuestionTakeaway.tsx`: 질문 복사와 실패 시 수동 복사 영역.
- `scripts/check-visit-flow.mjs`: 모든 도달 가능한 결과·중간 답변·보험 자격 모름·이전 지원·제품 확인 상태의 추천 질문 및 질문/결과 상태, 후속 답변 초기화, 미확인 분기, 질문 복사문 검사.
