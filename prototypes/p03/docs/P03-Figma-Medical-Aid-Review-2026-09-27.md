# P03 Figma 게시본 — 의료급여 분기·현재 위치·복귀 검토

검토일: 2026-09-27 (Asia/Seoul)

대상: https://ochre-bead-10600476.figma.site/validation/hearing-aid-health-insurance

이번 기록은 게시 화면을 실제 브라우저로 조작하고 화면·접근성 트리·렌더링된 DOM을 관찰한 결과다. 최신 Make 소스나 게시 버전 번호는 확보하지 않았다. 원본 로컬 P03과 최신 Make 구현을 동일한 코드로 취급하지 않는다. 애플리케이션 코드, Figma 프로젝트, 게시 상태를 변경하지 않았다.

## 1. 판정

의료급여의 처방전 질문과 신청 상태 4개 분기는 반영되었다. 제품 공식 원본 링크도 검색 전부터 표시된다. 그러나 현재 위치를 강조하는 색상 규칙, 신청 단계의 담당 기관 표시, 전체 기준 왕복 시 펼침·초점 보존은 보완이 필요하다.

## 2. 수정할 사항

### A. 처방전 없음·모름에서 두 단계가 강조됨

재현: 등록 완료 → 의료급여 → Q3 아직 안 받았어요 / 잘 모르겠어요.

| Q3 답변 | 결과 본문의 병원 처방 | 결과 본문의 구입·착용 |
| --- | --- | --- |
| 아직 안 받았어요 | 처방 받기 전, 배경 #FEF3C7 | 구입 전 신청·결정 필요, 배경 #FFFBEB |
| 잘 모르겠어요 | 처방 확인 필요, 배경 #FFFBEB | 구입 전 신청·결정 필요, 배경 #FFFBEB |

‘아직 안 받았어요’는 서로 다른 노란색 계열로 두 항목을 강조한다. ‘잘 모르겠어요’는 두 항목의 배경과 제목 강조가 동일하여 현재 확인할 위치가 구분되지 않는다. 상단 축약 과정에서는 처방전 모름일 때 두 항목 모두 #F5F3F0로 표시되어 본문과 강조 규칙도 다르다.

권장 수정:

- 이 두 결과에서는 병원 처방만 동일한 연노랑으로 강조한다.
- 미수령·미확인은 각각 문구로 보존한다. 강조한다고 처방 완료로 바꾸지 않는다.
- 구입·착용은 이후 과정의 중립 색상으로 표시한다. 필요한 보조 문구는 ‘처방 확인 후 신청·결정’ 등 미래 순서를 드러내도록 정리한다.
- 현재 먼저 확인할 위치와 확인 필요/미완료 같은 상태를 별개로 표현한다. 확인할 사항이 있다는 이유로 모든 단계를 현재 단계처럼 강조하지 않는다.
- 상단 축약 과정과 결과 본문에 같은 규칙을 적용한다. 단계를 펼쳤다는 이유로 개인의 현재 위치를 바꾸지 않는다.

이는 렌더링 관찰에 따른 판단이다. 정확한 함수·조건문 원인은 최신 소스 확인이 필요하다.

### B. 의료급여 신청 단계의 담당 기관 불일치

처방 완료 후 신청 대기·미신청·신청 상태 모름 결과에서 다음 행동은 주민센터 또는 시군구 담당자에게 문의하는 것이다. 그러나 강조된 ‘구입·착용’ 행은 기관을 ‘보청기센터 · 판매업소’로 표시한다.

권장 수정:

- 기존 5단계를 유지한다면 해당 행 안에 ‘구입 전 신청·결정 확인’을 하위 절차로 명시하고, 현재 담당 기관을 주민센터·시군구로 표시한다.
- 지원 가능 안내를 받았다는 결과에서는 제품 상담 단계와 센터를 표시한다.
- 단계의 기관·현재 상태·상단 다음 행동을 같은 결과 데이터에 맞춘다.

### C. 전체 기준 왕복의 펼침·초점 보존 미완료

재현:

1. 의료급여 신청 상태 모름 결과 → 전체 기준.
2. ‘이미 구입했는데 등록·처방 절차를 거치지 않았어요’를 펼침.
3. ‘센터·제품 등록 확인하기’ → Picasso 검색 → Starkey Picasso 1000 CIC 선택.
4. 하단 ‘전체 기준의 보던 곳으로 돌아가기’ 선택.

관찰:

- 복귀 대상과 스크롤 좌표 2249는 유지됨.
- 열어 둔 details는 닫힘: 복귀 전 열린 항목 1개 → 복귀 후 0개.
- 초점은 원래 진입 버튼이 아닌 BODY에 있음.
- 제품 화면 재진입 시 검색어·결과·선택 제품은 유지됨.
- 전체 기준에서 결과로 돌아오면 결과 제목에 초점이 도달하고 답변 사실은 유지됨.

권장 수정: 펼침 상태를 먼저 복원하고 배치가 반영된 뒤 읽던 위치를 복원한다. 전체 기준 복귀에서는 진입 버튼에 초점을 복원하되 초점 때문에 스크롤이 튀지 않게 한다. 기존 결과 제목으로의 초점 이동은 보존한다.

## 3. 반영 확인

- 의료급여 → 처방전 없음: 처방 진료 예약·검사 및 준비사항 문의 안내.
- 의료급여 → 처방전 모름: 병원에서 받은 서류가 지원 신청용 처방전인지 확인 안내.
- 처방전 있음 → 지원 가능 안내 받음: 센터 제품·비용 상담 안내.
- 처방전 있음 → 신청 대기: 접수 담당자에게 처리 상태·통지 방법 문의 안내.
- 처방전 있음 → 미신청: 처방전을 바탕으로 주민센터에 신청 방법 문의 안내.
- 처방전 있음 → 신청 상태 모름: 신청 기록과 처리 상태 확인 안내.
- 의료급여 결과에서 ‘제 제도가 확인되면’ 문구 제거 및 각 결과의 상담 질문 제공.
- 의료급여 결과에 건강보험 개인 지급액·지원율 카드가 노출되지 않음.
- 처방전 모름 및 신청 상태 모름 결과의 실제 복사문이 화면 상태·질문과 일치함.
- ‘지금 할 일 보기’ 클릭 시 today-tasks 제목으로 초점 이동 확인.
- 제품 공식 원본 링크와 기존 확인일 2026-09-23이 검색 전·검색 후·제품 선택 후 표시됨.
- 전체 기준과 제품 화면 왕복 시 Picasso 검색 결과 및 선택 제품 보존 확인.
- 의료급여의 처방 답변 변경 후 이전 신청 결과가 사라짐.
- 의료급여에서 보험 자격 미확인으로 바꾼 뒤 처방전 없음 선택 시 미확인 결과로 변경되고 의료급여 신청 상태·금액이 잔류하지 않음.

## 4. 검증 범위와 한계

- 데스크톱: 의료급여 결과 6개, 대표 복사 2개, 다음 행동 이동, 전체 기준·제품 왕복 및 선택 보존을 조작함.
- 390px·320px 브라우저 뷰포트: 의료급여 처방전 모름 결과의 줄바꿈·단계 표시·문서 가로 넘침을 확인함. 해당 화면에서 가로 넘침은 관찰되지 않음. 상단/본문 강조 불일치와 두 단계 노란색은 남아 있음.
- 실제 모바일 기기, 모든 결과의 모바일 화면, 화면낭독기, 키보드 전체 탐색, 복사 실패 대체 동작은 이번에 검증하지 않음.
- 건강보험의 모든 기존 결과 및 보험 미확인 전체 조합을 다시 검사하지 않음. 보험 미확인+처방전 없음 대표 경로만 확인함.
- 제품 검색 결과 없음 상태의 원본 링크는 이번에 별도 검증하지 않음.
- 최신 Make 소스를 받지 않았으므로 타입 검사·테스트·빌드를 수행하지 않음. 기존 로컬 앱 검사로 최신 게시본의 품질을 대신 증명하지 않음.
- 지원 금액·법적 기준의 새로운 전수 재조사는 이번 범위에 포함하지 않음.
