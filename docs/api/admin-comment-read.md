# 관리자 게시글별 댓글 조회 API

## 목적

관리자가 게시글에 속한 댓글을 조회하고,
댓글의 본문과 숨김·삭제 상태를 확인한다.

정상·숨김·삭제 게시글 모두 관리자 조회를 허용한다.
일반 공개 조회의 노출 정책은 변경하지 않는다.

## 요청

GET /api/v1/admin/posts/{postId}/comments

### 인증

- 로그인 세션 쿠키가 필요하다.
- 현재 회원 상태가 ACTIVE이고 역할이 ADMIN이어야 한다.
- 세션의 인증 버전·역할이 현재 DB 정보와 일치해야 한다.
- GET 요청이므로 CSRF 토큰은 필요하지 않다.

### 경로 변수

| 이름 | 타입 | 설명 |
|---|---|---|
| postId | Long | 조회할 게시글 ID |

### 조회 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| status | ALL | ALL, VISIBLE, HIDDEN, DELETED |
| keyword | 없음 | 댓글 본문 부분 검색 |
| page | 0 | 0부터 시작하는 페이지 번호 |
| size | 20 | 페이지 크기, 1~50 |

### 검색·페이지 정책

- status 값은 대문자로 전달한다.
- keyword는 앞뒤 공백을 제거한다.
- keyword가 없거나 공백뿐이면 검색 조건을 제외한다.
- keyword는 공백 제거 후 Unicode 코드 포인트 기준 최대 100자다.
- 영문 대소문자를 구분하지 않는 본문 부분 검색이다.
- 검색어의 %, _, !는 와일드카드가 아닌 일반 문자로 처리한다.
- 게시글 제목이나 작성자 닉네임은 검색 대상이 아니다.
- page는 0 이상이어야 한다.
- page × size는 Integer.MAX_VALUE 이하여야 한다.
- 작성 시각 오름차순, 같은 시각이면 댓글 ID 오름차순으로 조회한다.
- 사용자 지정 sort 파라미터는 제공하지 않는다.

### 상태 필터

상태 필터는 부모 게시글이 아닌 댓글 자체의 상태에 적용한다.

| 상태 | 조건 |
|---|---|
| ALL | 댓글 상태에 따른 제한 없음 |
| VISIBLE | 삭제되지 않았고 개별 숨김 상태도 아님 |
| HIDDEN | 삭제되지 않았으며 개별 숨김 상태임 |
| DELETED | 삭제된 댓글. 숨김 이력 유무와 무관함 |

숨김 이후 삭제한 댓글은 DELETED로 분류한다.

## 성공 응답

HTTP 200 OK
Cache-Control: no-store

```json
{
  "postId": 123,
  "postStatus": "HIDDEN",
  "items": [
    {
      "commentId": 456,
      "content": "댓글 본문입니다.",
      "author": {
        "memberId": 8,
        "nickname": "댓글작성회원",
        "withdrawn": false
      },
      "status": "VISIBLE",
      "createdAt": "2026-10-30T10:00:00Z",
      "updatedAt": "2026-10-30T10:00:00Z",
      "hiddenAt": null,
      "deletedAt": null
    }
  ],
  "page": 0,
  "size": 20,
  "totalElements": 1,
  "totalPages": 1,
  "hasNext": false,
  "hasPrevious": false
}
```

### 응답 해석

- postStatus는 게시글 자체의 상태다.
- items[].status는 댓글 자체의 상태다.
- 실제 콘텐츠 상태로 ALL이 반환되지는 않는다.
- 숨김 게시글 아래의 댓글도 자체 상태는 VISIBLE일 수 있다.
- 이때 VISIBLE은 일반 사용자에게 공개된다는 의미가 아니다.
- 숨김·삭제 댓글도 관리자 응답에는 전체 본문을 반환한다.
- 탈퇴한 작성자는 nickname="탈퇴한 회원", withdrawn=true로 반환한다.
- 작성자의 이메일·비밀번호 해시는 반환하지 않는다.
- totalElements는 해당 게시글에서 상태·검색 조건에 맞는 댓글 수다.
- 댓글이 없으면 items=[]이며 totalElements와 totalPages는 0이다.
- 범위를 벗어난 페이지는 items=[]로 반환하되 전체 개수를 유지한다.
- 날짜·시간은 시간대 정보가 포함된 ISO 8601 형식이다.

## 주요 오류

| HTTP 상태 | code | 설명 |
|---|---|---|
| 400 | INVALID_REQUEST_PARAMETER | 상태 값·숫자 등 요청 파라미터 변환 실패 |
| 400 | INVALID_PAGE_REQUEST | 페이지 번호·크기·조회 시작 위치 제한 위반 |
| 400 | INVALID_SEARCH_KEYWORD | 검색어 길이 제한 위반 |
| 401 | AUTHENTICATION_REQUIRED | 비로그인 또는 유효하지 않은 인증 정보 |
| 403 | ACCESS_DENIED | 보안 필터에서 일반 회원의 접근 차단 |
| 403 | ADMIN_REQUIRED | 서비스에서 현재 관리자 권한이 없음을 확인 |
| 404 | POST_NOT_FOUND | 게시글이 존재하지 않거나 ID가 유효하지 않음 |

## 프론트 연동 유의사항

- API 요청에 세션 쿠키를 포함한다.
- 상태·검색어·페이지 크기를 변경하면 page를 0으로 초기화한다.
- 게시글 ID와 조회 조건을 구분하여 응답을 관리한다.
- 이전 조회 조건의 늦은 응답이 현재 목록을 덮어쓰지 않게 한다.
- 숨김·복원 성공 후 현재 조회 조건으로 댓글 목록을 갱신한다.
- 필터 조건에서 제외된 댓글은 목록에서 사라질 수 있다.
- 변경 후 현재 페이지가 범위를 벗어나면 유효한 페이지로 조정한다.
- 게시글 상태와 댓글 상태를 각각 표시한다.
- 본문은 일반 텍스트로 렌더링한다.
- 관리자 응답을 일반 공개 화면의 데이터로 재사용하지 않는다.

## 조회와 변경 정책의 구분

삭제된 게시글의 댓글도 관리자 조회는 가능하다.

그러나 조회 가능 여부가 숨김·복원 가능 여부를 의미하지 않는다.
삭제된 부모 게시글 또는 삭제된 댓글의 변경 제한은
기존 관리자 숨김·복원 API 정책을 따른다.
