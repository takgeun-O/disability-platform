# 회원 관리 요약 연동 (2026-11-18)

회원 관리 제목 아래에 현재 회원 / 오늘 가입 / 인증 대기 / 이용 정지 카드를 표시한다. 단위는 명이며 천 단위 구분을 적용한다. 관리자를 포함한 전체 집계로, 목록 검색·상태·권한·정렬·페이지와 독립적이다. 카드는 필터나 이동 동작을 제공하지 않는다.

## 계약과 갱신

- `GET /api/v1/admin/members/summary`: 기존 세션 쿠키·no-store GET 클라이언트 사용. 요청 본문·쿼리·CSRF 헤더 없음.
- 모든 필드의 존재·non-null 및 날짜/시각·0 이상의 안전한 정수를 검사한다. 잘못된 응답을 0이나 목록 개수로 대체하지 않는다.
- baseDate는 날짜 문자열 그대로 표시하고 queriedAt만 한국 시간으로 변환한다.
- 화면 진입, 요약 새로고침, 정지·해제 API 성공 후 조회한다. 목록 필터나 상세 선택만으로 다시 조회하지 않는다.
- 정지·해제 성공의 changed=false도 서버 확인을 위해 요약을 갱신한다. 조치 실패·불확실한 결과 및 기존 GET 복구는 성공으로 간주하지 않는다.
- 요약 오류는 회원 조치 성공을 바꾸지 않는다. 재시도는 요약 GET만 실행하며 기존 목록·상세·조치 이력의 갱신 흐름을 유지한다.
- AbortController와 요청 동일성·현재 인증 세대 확인으로 지연 응답을 차단한다. 401·403은 기존 관리자 보호 흐름으로 회원 정보와 요약을 숨긴다.

## 표시와 접근성

첫 조회 중/실패는 미조회 기호로 표시하고 실제 0과 구분한다. 재조회 중 또는 실패 시 이전 수치·조회 시각을 유지하며 이전 결과임을 표시한다. 정상 완료 안내는 빈 줄 없이 스크린리더용 status로 제공한다. 새로고침은 키보드 접근·포커스를 유지하고 중복 요청을 막는다.

기존 회원 workspace 컨테이너 너비에 따라 4/2/1열로 배치한다. 좁은 화면은 제목과 수치를 나란히 배치하되 긴 숫자는 줄바꿈한다. 모바일 상세 전환 시 요약도 기존 검색 영역과 함께 숨기고 목록 복귀 시 다시 표시한다. 공통 대시보드 CSS는 수정하지 않는다.

## 검증 범위와 한계

단위 테스트는 계약·오류 보존을 확인하고, 신규 브라우저 테스트는 카드 매핑, 날짜, 0/로딩/오류, 필터 독립성, 정지·해제 후 갱신, 요약 실패와 조치 성공 구분, 지연 응답·401/403·화면 이탈을 모의 API로 확인한다. 1920/1440/900/390/320px 및 CSS zoom=2 화면에서 긴 숫자의 실제 텍스트 영역이 카드 안에 들어오는지도 검사한다. CSS 확대는 브라우저 UI의 네이티브 확대 조작과 구분한다.

기존 회원 브라우저 fixture에는 요약 경로를 명시적으로 추가했다. 상세 선조회 금지 검증은 숫자 회원 ID 경로를 검사하고, 불확실한 조치의 성공 안내 금지는 회원 운영 영역으로 한정했다. 요약 조회 완료 알림은 조치 완료 알림이 아니며 기존 검증 목적은 유지된다.

실행 중인 로컬 Spring 서버(8082)는 관리자 세션의 회원 요약 GET에 400 INVALID_REQUEST_PARAMETER를 반환했고 해당 OpenAPI에는 회원 요약 경로가 없었다. 실행 서버와 최신 소스가 일치하지 않아 실제 카드/정지·해제 후 요약 갱신 검증은 미실행이다. 기존 서버 재시작이나 회원 상태 변경은 하지 않았다. 최신 백엔드 실행 후 허용된 테스트 회원으로 응답과 카드 대조, 정지→재조회→해제→재조회 및 원상 복원을 별도로 확인해야 한다.

이번 실행의 정확한 명령·결과 및 최종 캡처는 Downloads 검토 ZIP의 README_REVIEW.md와 logs/final-*를 참조한다. 이전 백엔드 테스트 결과를 이번 실행 결과로 합산하지 않는다.
