# 신고 관리 요약 카드 — 2026-11-17

## 표시와 계약

`GET /api/v1/admin/reports/summary`를 기존 세션 인증 GET 클라이언트로 호출한다. 요청 본문·필터·CSRF 헤더를 추가하지 않는다. 세 수치·queriedAt·baseDate는 필수 non-null이며 런타임 검증에 실패하면 오류로 처리한다. 누락 값을 0으로 대체하지 않는다.

제목 아래, 필터 위에 처리 대기(전체 기간 · 접수 상태), 오늘 접수(오늘 접수된 전체 신고), 오늘 종결(처리 완료·기각 포함)을 표시한다. 대시보드 카드 스타일을 재사용하고 3열/2열/1열로 전환한다. 카드는 이동·필터 기능이 없다. baseDate는 날짜 문자열을 그대로 표시하며 queriedAt만 기존 한국 시간 포맷터로 표시한다. 오늘 종결은 handledAt 기준이고, 목록 접수일 조건과 무관하다. 요약과 목록은 같은 DB 스냅샷을 보장하지 않는다.

## 조회와 보호

- 신고 관리 진입, 요약 새로고침, 목록 상세의 확정된 hide-and-resolve/resolve/dismiss 성공 후 GET을 실행한다.
- URL별 목록 화면 바깥에 요약 상태를 두어 필터·정렬·페이지·선택 변경은 요약 요청을 반복하지 않는다.
- 대시보드 모달·전용 상세에서 처리 후 신고 관리로 진입하면 새로 조회한다. 별도 전역 캐시나 폴링은 없다.
- 요약 실패는 목록/상세 복구 잠금과 별개다. 성공 POST를 재전송하지 않고 처리 결과·입력·포커스를 유지한다.
- 최초 로딩·실패에는 숫자를 표시하지 않는다. 갱신 중/실패에는 이전 수치와 조회 시각을 구분해 유지한다.
- AbortController, 요청 식별, 현재 회원 세션 검사로 늦은 결과를 차단한다. 페이지 이탈 시 취소한다. 401·403은 기존 인증/권한 보호로 목록·상세·요약을 함께 숨긴다.

## 검증 범위

단위 테스트는 계약·필수 필드·숫자 범위·오류 전달과 세션 GET을 검증한다. 브라우저 테스트는 합성 관리자/API 응답만 사용한다. 정상/0/로딩/오류/재시도, 필터 독립성, 세 처리 동작과 후속 실패, 늦은 응답, 인증 보호, 전용 상세 및 모달 복귀를 검증한다. 1920/1440/390/320px와 America/Los_Angeles 시간대에서 한국 날짜·시각을 확인한다.

실제 관리자 백엔드 처리 연동은 이번에 실행하지 않았다. 테스트 전용 신고로 세 처리 동작을 각각 실행하고, 요약 GET 재호출과 처리 대기/오늘 종결 반영, 모달·전용 상세에서 목록 복귀를 확인하면 된다. 실제 사용자 신고나 DB를 임의로 변경하지 않는다. 명령별 실제 결과와 제한은 검토 ZIP의 README_REVIEW.md에 기록한다.
