# 댓글 편집 전환 개선

시작 브랜치 feat/community-post-like, HEAD 89cddc5a45def18da3cfa45cc4009d7df0ef8ab6. 시작 작업 트리는 깨끗했으며 기존 구현을 보존했다.

## 원인과 변경
Comments.tsx는 editor가 있으면 다른 수정 버튼을 disabled로 만들었고 삭제 대화상자는 별도로 열어 기존 편집 폼이 남았다.

- 다른 댓글 수정/삭제와 편집 취소를 명시적인 전환 동작으로 통합.
- 입력 변경 없으면 즉시 편집 종료 후 선택 동작 수행.
- 입력 변경 있으면 버리기 확인. 취소/Escape는 초안 유지, 승인 후에만 전환.
- 삭제는 편집 종료 후 별도의 삭제 확인을 거치며 버리기 승인 자체로 DELETE하지 않음.
- 확인 완료 시 현재 댓글 목록과 작성자 권한을 다시 확인. 저장 요청 중 전환 금지.
- 새 댓글 작성 초안, 목록 새로고침 시 편집 보존, 사라진 댓글의 초안 보관, 이탈 보호 유지.
- React 정적 검사가 감지한 load 선언 전 접근을 해소하기 위해 함수 위치를 이동. 인증 변경 재조회는 취소 가능한 마이크로태스크에서 실행하여 정리된 효과가 재조회를 시작하지 않도록 했다.
