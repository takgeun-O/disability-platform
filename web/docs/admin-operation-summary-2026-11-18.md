# 운영 기록 요약 연동 (2026-11-18)

## 표시·갱신

운영 기록 제목 아래에 전체 운영 기록 / 오늘 운영 기록 / 오늘 숨김 / 오늘 숨김 해제 카드를 표시한다. 콘텐츠 개수가 아닌 저장된 숨김·해제 기록 건수이며, 목록 필터와 독립적이다. [API 계약](../../docs/api/admin-operation-summary.md)을 따른다.

`AdminOperationSummary`의 요청은 목록 URL 상태와 분리한다. 화면 진입, 수동 새로고침, 현재 운영 패널의 숨김·해제 성공 시 GET을 실행한다. 목록·상세 재조회는 기존 `AdminModeration` 흐름을 유지한다. 요약 실패로 POST를 재실행하거나 완료된 조치를 실패로 바꾸지 않는다.

baseDate는 문자열 날짜 그대로 표시하고 queriedAt만 한국 시간으로 포맷한다. 미조회/오류는 0으로 대체하지 않는다. 재조회 실패는 이전 수치·시각과 오류를 함께 표시한다. 성공 알림은 live region에만 두고 빈 줄을 만들지 않는다. 요청 취소·세션 세대 검사로 늦은 응답을 차단한다.

## 우측 패널 회귀 보완

요약 카드가 추가되면서 패널 시작 위치가 낮아졌다. 기존 패널은 현재 시작 위치부터 화면 하단까지의 공간만 예약하여, 일부 창 크기 변경에서 조치 폼과 오류가 화면 아래에 남았다. 조치 중에는 화면 높이에 해당하는 패널 공간을 먼저 확보하고, 측정 후 패널 상단을 화면 안으로 이동한다. 일반 상세 읽기 모드의 높이 계산과 목록 복귀 위치·포커스 복원은 유지한다. 예약된 animation frame은 측정 갱신/해제 시 취소한다.

작업 전 HEAD의 별도 복사본에서 경계 너비 변경, 읽던 문단 보존, 오류 필드 보존 3건을 비교 실행했다. 작업 전에는 통과하고 요약 추가 직후 실패한 회귀를 위 수정으로 해결한다.

`admin-action-workspace-browser.mjs`는 이전 모달의 ‘이 게시글 관리/이 댓글 관리’ 진입과 가로 2단 배치를 기대했다. 작업 전 복사본에서도 해당 버튼 탐색 실패를 재현했다. 현재 우측 패널의 직접 조치 진입·본문 다음 폼 배치·상세 닫기 후 선택 행 포커스로 갱신한다. 전체 본문, 필수 사유, 반복 서버 오류, 오류 필드 포커스와 가시성, 성공 안내, 키보드·모바일 검증 목적은 유지한다. 게시글 목록에서 여는 기존 모달 테스트는 유지한다.

## 검증 구분

- 새 요약 브라우저 테스트: API 응답을 가로채는 모의 API 검증. 0/로딩/실패/재시도, 필터 독립성, 조치 성공 후 갱신, 실패한 조치, 지연 응답, 인증 오류, 메뉴 이동을 확인한다.
- 운영 기록·현재 대상·패널·조치 작업공간 브라우저 회귀: 현재 우측 패널 구조를 기준으로 실행한다.
- 실제 로컬 Spring 세션 연동: 승인된 합성 계정과 새 검증 게시글만 사용한다. 응답 모의 생성 없이 요약 GET과 화면 수치를 비교하고 숨김·해제 후 서버 집계를 확인한다. 인증정보와 일반 개발 콘텐츠는 검토 자료에 포함하지 않는다.
- 상세 실행 명령, 최종 결과, 비교 실패 로그 및 캡처는 이번 검토 ZIP의 README_REVIEW.md와 logs/results에 기록한다.
