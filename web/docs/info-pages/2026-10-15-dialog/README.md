# P03 안내 모달 — 2026-10-15

실제 Next.js 프로덕션 화면을 Chrome에서 캡처했다. 정적 시안이 아니다. 설문·정책·제품 검색은 실제 프론트엔드 로직이며 헤더의 `/me`만 비로그인 모의 응답을 사용했다. 테스트 데이터 생성이나 DB 쓰기는 없다.

키보드 Enter로 연 화면이므로 안내 제목의 초점 테두리가 보인다. 긴 기준 본문은 모달 안에서 스크롤하고, 상단 닫기 버튼은 고정된다. `summary`는 승인된 6차의 간결한 두 항목을 재사용한다. 전체 기준의 금액·조건·출처는 변경하지 않았다.

[검증 결과](verification.json): 모달 9개, 기존 정보 페이지 15개, 단위 167개 통과. 타입·lint·프로덕션 빌드 통과. 정책 25개 선언과 공통 정책 컴포넌트 3개를 HEAD와 동일 비교했다. [상세 학습 기록](../../Info-Pages-Integration-2026-10-14.md#2026-10-15-후속-수정-설문-위에서-읽는-안내-모달).

직접 확인: 보청기 안내에서 답변 → 체크 → 30초 요약/전체 기준/양쪽 지원 → 닫기 또는 Esc. 답변·체크·펼침과 스크롤이 유지되고 처음 누른 버튼으로 초점이 돌아온다. 요약에서 전체 기준을 열어도 닫으면 원래 설문으로 돌아온다.
