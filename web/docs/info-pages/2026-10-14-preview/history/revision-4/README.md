## 현재 검토 방향

1. **보청기 시작 화면: 질문부터 시작하는 방향에 사용자 동의(2026-10-14).** 답변 후 질문을 없애지 않고, 질문·선택 내용을 유지하며 하단에 기관·문의·준비·다음 단계를 표시하도록 수정했다. 정책 설명과 금액은 기존 표시 조건에 맞는 상세 영역에 유지한다.
2. **현재 복지 목록:** 한 건인 동안 검색/필터 없이 시작하는 안을 권장한다. 콘텐츠가 늘었을 때 확장 시안의 필터를 도입한다. 실제 필터 데이터/API 도입은 별도 범위다.

나머지 소개 문구와 정보 위계를 함께 검토하면 된다. 확정된 상단 메뉴 순서는 선택 사항으로 되묻지 않는다. **사용자 방향 확인 전 실제 서비스에는 반영하지 않는다.**

## 이번 확인 순서

1. 소개에서 전체 서비스 설명과 하단의 ‘현재 이용 가능 / 앞으로의 방향’을 비교한다.
2. 보청기 시작에서 등록 완료 → 건강보험 → 처방전 있음 → 처음 신청 순으로 선택한다. 다음 질문과 결과로 부드럽게 이동하고, 이전 질문은 위에 남는다.
3. 위의 ‘전체 절차와 내 위치’를 확인한다. 모바일에서는 제목을 눌러 펼친다. 등록·처방은 초록, 구입·착용은 노랑이다. 각 단계를 눌러 설명을 열고 다시 눌러 닫는다.
4. 이후 관리 설명을 열어도 구입·착용의 현재 상태는 바뀌지 않는다. 이전 답변을 변경하면 질문·결과·상태가 새 답변에 맞게 갱신된다.

현재 서비스 전체 빌드·인증 API 검증은 이번 시안 작업에서 재실행하지 않았다. 브라우저 검사는 독립 시안과 기존 P03의 읽기 전용 비교이며, 실제 API 연동 검증으로 간주하지 않는다.
