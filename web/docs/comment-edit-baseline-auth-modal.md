# 댓글 수정 기준값과 인증 만료 안내 (2026-11-05)

최신 유효 댓글 조회에서 확인한 `confirmed.content`를 저장 여부·수정 취소·편집 전환·페이지 이탈 판단의 공통 기준으로 사용한다. `original`은 편집 시작 본문으로 충돌 안내에 남긴다. 조회는 `value`를 변경하지 않으며 대상 부재나 조회 실패는 기존 기준을 유지한다. `contentUpdatedAt`은 조회한 값을 그대로 사용한다.

현재 화면/회원 요청 소유권이 유효한 수정 PUT에서 `401 / AUTHENTICATION_REQUIRED`가 확인되면 인증을 만료 처리하고 공용 대화상자로 다시 로그인을 안내한다. 이 사건에 한해 전역 만료 토스트를 억제한다. 다른 만료 처리의 기본 알림은 유지한다. 인증 세대가 바뀐 뒤의 요청은 다시 모달을 열거나 새 회원을 로그아웃시킬 수 없다.

수정 초안은 인증 상실 시 정리한다. 독립적인 새 댓글 초안은 기존 정책대로 보호한다. 로그인 이동은 기존 NavigationGuard와 안전한 from 경로를 사용하며 초안 전달·자동 저장·자동 복원은 없다. 일반 403, CSRF, 네트워크/5xx, 초기 비로그인, 직접 로그아웃은 이 모달의 자동 표시 조건이 아니다.

검증은 제어 가능한 mock API와 최종 production build로 수행한다. 서버의 동시 수정 충돌 방지나 실제 Spring 인증 연동을 새로 검증한 작업은 아니다. 상세 실행 로그와 결과는 이번 검토 ZIP의 README_REVIEW.md 및 verification/에 기록한다.
