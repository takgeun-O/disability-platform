## 범위와 기준
- 브랜치: feat/admin-operation-log
- 기준 HEAD: d9decf224a46453c4e7e188a0299bc7096c44eb7
- 기존 목록/상세 패널 및 행 선택 미커밋 작업 위에서 작업했습니다. task-only.patch는 이번 작업 시작 시점의 실제 파일 스냅샷과 비교합니다.
- 백엔드, DB, API, 공개 화면의 제품 코드는 변경하지 않았습니다. 커밋·푸시·병합·배포하지 않았습니다.

## 변경 내용
- AdminPosts / AdminOperationLogs: 제목·게시글 대상의 일반 클릭 및 Enter를 onNavigate에서 패널 선택으로 처리합니다. AppLink가 이 preventDefault를 존중하므로 화면 이탈 통지는 발생하지 않습니다. 실제 href는 유지하고 수정키·가운데 버튼·새 탭은 상세 페이지로 이동합니다. 행 선택과 중복 처리하지 않으며 드래그된 텍스트, 조회 중 stale 결과, 조치 잠금도 유지합니다. 선택만으로 목록 API를 호출하지 않습니다.
- AdminDateRange: native details/summary로 적용 기간을 요약합니다. 열어서 입력·달력·빠른 기간을 사용합니다. 미적용 날짜는 닫아도 적용되지 않으며 입력 초안은 유지합니다. 유효한 적용은 설정을 닫고 summary로 포커스를 반환합니다. 잘못된 날짜는 펼친 영역에 오류를 유지하고 요청하지 않습니다. Esc/명시적 닫기 지원, 전체 초기화 시 기존 key를 통한 날짜 초안 초기화 유지.
- admin.css: 관리자에만 적용한 압축 도구 모음과 별도 목록/상세 카드. 목록의 작성자·분류는 제목 아래, 운영 기록의 관리자 정보는 상세 패널에서 확인합니다. 1100px 이하 기존 단일 열 정책 유지. 실제 로고 헤더 폭을 관리자 공간과 맞추고 사이드바의 중복 IYUM 문구를 ‘관리자 메뉴’로 정리했습니다. CSS zoom/scale과 일괄 글자 축소는 사용하지 않았습니다.
- AdminSelectionPanel: ‘상세 닫기’로 선택만 해제하고 해당 행으로 포커스를 반환합니다.
- AdminPostPreview: 명시적 상세 관리/서비스 링크를 상단에 배치했습니다. 제목·상태, 작성자·분류·시각, 본문, 운영 조치 순서이며 긴 본문은 키보드 접근 가능한 스크롤 영역에서 전체를 읽을 수 있습니다.
- AdminLogPreview: 처리 사유 원문 보존, null/동일 상세 사유의 불필요한 영역 제거, 다른 상세만 별도 표시. 한국 시간 및 과거 기록 설명의 중복을 줄이고 현재 게시글 내용은 별도 구분합니다.

API는 기존 관리자 게시글 목록·상세, 운영 기록 목록 및 숨김/해제만 재사용합니다. selected는 목록 API 조건에 포함하지 않습니다. 댓글 기록의 본문/부모 링크는 현재 계약에 없어 추가하지 않았습니다.

## 회귀 테스트 변경 이유
- 날짜 컨트롤이 기본 접힘으로 바뀌어 테스트에서도 summary를 클릭한 뒤 실제 필드를 조작합니다. 날짜 검증·미적용 입력·정렬·범위/페이지·오류 assertion을 유지했습니다.
- 제목 클릭 후 댓글 전체 관리로 진입하던 기존 테스트는 제목 선택 → 패널의 상세 관리 링크 순서로 바꿨습니다. 이후 인증/늦은 응답/조치 assertion은 유지했습니다.
- 조회 중 제목 선택이 잠기는 정책에 맞춰 history의 늦은 목록 GET 검증은 실제 ‘서비스로 돌아가기’ 링크 → 브라우저 뒤로가기를 사용합니다. 취소를 무시하는 늦은 응답을 끝까지 완료하고 최신 목록/오류/로딩 상태를 검증합니다. 상세 이동·복귀 검증은 별도 history/master 시나리오에서 유지합니다.
- 이동된 작성자·관리자 정보는 새 표시 위치에서 검증합니다. 데스크톱 기록 표는 관리자 열을 상세로 옮긴 4열이고 좁은 화면의 기존 표 의미는 유지합니다.
- 신규 검증: 1440/1920/320에서 접힌 기간·미적용 닫기/Esc·Enter/일반 클릭·가운데 버튼/Meta 새 탭·텍스트 선택·목록 추가 요청 없음·독립 카드 정렬·긴 제목/닉네임/본문·사유 중복 제거.

## 실패 기록과 제한
첫 실행에서는 적용 뒤 열려 있던 기간 설정이 상세 링크를 가렸습니다. 유효한 적용 후 닫는 동작으로 보완했습니다. 기존 테스트의 숨겨진 옛 정보 열/제목 즉시 페이지 이동 기대값도 새 UI의 실제 접근 경로로 갱신했으며 검증을 삭제하거나 시간제한을 늘리지 않았습니다. 중간 로그는 earlier/로 최종 로그와 구분합니다.

공개 smoke는 기준 HEAD에서도 CommunityListPage/PostList를 사용하는 /community에 대해 이전 ‘질문과 경험을 함께’를 기대합니다. 실제 고정 안내는 ‘서로의 질문과 경험을 나눠요.’입니다. 관련 공개 제품 파일과 smoke 파일은 이번 시작 스냅샷 및 HEAD와 동일함을 SHA256/내용 비교로 확인했습니다. 관리자 변경의 회귀가 아니므로 범위 밖 테스트를 수정하지 않았습니다. smoke는 여기서 중단되어 후속 공개 Spring SSR 검증은 실행되지 않았습니다. 전체 테스트가 모두 통과했다고 표현하지 않습니다.

별도의 실제 계정 검증, 운영 환경 폰트 렌더링은 미검증입니다. 실제 환경에서는 두 관리자 목록에서 기간/상태/정렬 후 제목 선택, 상세 관리 이동 및 양쪽 복귀, 운영 조치 후 현재 필터 반영을 확인해 주세요. 사용자 데이터나 계정은 테스트를 위해 수정하지 않았습니다.
