# 홈·공통 UI 개편 및 병합 전 검증 — 2026-10-13

## 변경 범위

로그인 기준은 `6c7a2de21e05de843c2daa5de6229df64efee89f`다. 홈과 공통 헤더·푸터·메뉴·검색을 밝은 흰색/청회색, 네이비 본문, 청록 강조로 정리했다. 기존 인증 API 클라이언트, 세션·CSRF, 작성 이탈 확인, 로그아웃 타이머, 가입/이메일 인증, P03 내용은 보존했다.

- [HomePage](../src/features/HomePage.tsx): 실제 HTML 검색·바로가기·기존 커뮤니티 예시 목록과 장식 이미지.
- [Shell](../src/components/Shell.tsx), [GlobalNav](../src/components/GlobalNav.tsx): 로고, 본문 바로가기, 정보 찾기/커뮤니티/IYUM 소개, 반응형 메뉴와 키보드 초점.
- [DeadlinePanel](../src/components/DeadlinePanel.tsx): 데스크톱 오른쪽 정보 가이드 위, 모바일 바로가기 다음에 배치. 기본은 빈 상태이며 펼친 가상 공고 3개는 예시와 고정 기준일을 명시한다. 실제 정책 API는 추가하지 않았다.
- [iyum.css](../src/styles/iyum.css): 공통 색상·버튼·입력·카드·알림 및 1440/390px 배치. 본문 14–17px, 홈 제목 최대 50px, 조작 요소 최소 44px, 가시적인 초점과 움직임 감소 설정.
- [AuthControls](../src/components/AuthControls.tsx): 표시 클래스와 조작 영역만 변경. 인증·알림 처리 로직은 기준 커밋과 동일하다.

검색 결과와 게시글은 기존 모의 데이터다. 기기·기관 및 센터 방문 가이드는 준비 중으로 표시한다. 인증·커뮤니티·P03 개별 화면 전체 디자인 개편은 후속 범위다.

## 첨부 리뷰 패치

[ui-refresh-browser.mjs](../tests/ui-refresh-browser.mjs)의 비로그인 401 모의 응답에 실제 오류 계약의 `message`와 `fieldErrors`를 추가했다. 이전의 불완전한 응답은 클라이언트에서 인증 상태 미확인 오류로 처리될 수 있었다. 로그아웃 뒤 390/1440px에서 새로고침해 로그인·회원가입 메뉴, 로그아웃 버튼 부재, 상태 오류 부재, 가로 넘침을 확인하는 회귀 검사를 추가했다. 첨부 패치는 `git apply --check` 후 적용했고 서비스 로직 변경은 없다.
